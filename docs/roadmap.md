# 0.3.0 overview

Full list: [patch notes](changelog.md).

## Defaults

| Setting | New game | Save from 0.2.45 |
|---|---|---|
| War level | Retaliate | Matches War fleets |
| Retake your lost colonies | On | Off |
| Faction stances | All Auto | From faction priorities |
| New colonies | Off | Off |
| Payback horizon | 36 months, up to 120 | Same |

## Open items

- TME projects and paid moves: spend in their own steps. Planned: move into the planner queue.
- `legacyPlanner`: hidden switch for the 0.2.45 build engine.
- Not tested in game: bombardment, colony fleets, rebellions, commissioned invasions, ceasefire answers, Stand down refunds.
- Updating: back up saves. A 0.3.0 save cannot load in 0.2.45.x.
- Reports: [issues](https://github.com/Mjolniar/auto-colonies/issues).
