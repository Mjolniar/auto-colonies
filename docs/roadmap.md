# 0.3.0 overview

The full list is in the [patch notes](changelog.md).

## Defaults

| Setting | New game | Save from 0.2.45 |
|---|---|---|
| War level | Retaliate | Matches War fleets |
| Retake your lost colonies | On | Off |
| Faction stances | All Auto | From faction priorities |
| New colonies | Off | Off |
| Payback horizon | 36 months, up to 120 | Same |

## Open items

- TME projects and paid moves still spend in their own steps. I'm planning to move them into the planner queue.
- `legacyPlanner` is a hidden switch for the 0.2.45 build engine.
- Back up your saves before updating, since a 0.3.0 save can't load in 0.2.45.x.
- If anything weird happens, let me know in [issues](https://github.com/Mjolniar/auto-colonies/issues).
